# Security policy

## Supported versions

Security fixes go into the latest release only. Until 1.0, that is the
latest 0.x version.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub:
[open a private report](https://github.com/kmoneil/zig-gcp-pubsub/security/advisories/new).
Please do not open a public issue.

Include the version, what goes wrong, and the steps or input that reproduce
it. Useful examples: a server or network peer that can crash the client,
credentials or message data that leak into logs or reach a plain-HTTP
endpoint, and TLS checks that can be bypassed.
